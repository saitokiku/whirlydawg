# Step 2 – cut and curl the blades (make ONE first)

You need **20 blades**, 4 from each 11.75 × 3.75 in piece of 1.6 mm aluminium, so 5 pieces.
Each blade is curled **across its width** into a shallow scoop and stays straight along its length.

| File | Use |
|---|---|
| `blade_and_roof_templates_1to1.pdf` | **Print at 100 % / actual size.** Page 1: blade cutting template plus a 1:1 **cup gauge** to check the curl. Page 2: how to get 4 blades from each 11.75 × 3.75 in piece. Page 3: roof hole and screw template. Check the 50 mm bar with a ruler before cutting. |
| `blade_forming_die_lower.stl` + `blade_forming_die_upper.stl` | Printed curl die: lay the flat blade between the 4 posts, squeeze in a bench vise, done. |
| `blade_flat_pattern_single_TEST.dxf` | one blade outline for a laser/CNC/water-jet cutter |
| `blade_flat_pattern_all_blades.dxf` | all 20 blades laid out on 5 pieces of your stock |
| `blade_template_1to1.svg` | same outline as a vector image (Inkscape, cutters) |

Step-by-step instructions: `PRINT_AND_ASSEMBLE.md`, Phase 1.
