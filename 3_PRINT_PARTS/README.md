# Step 3 – print the parts

All files are **already oriented for printing**. In Bambu Studio, import them and do **not**
auto-orient. Settings for each part are in `PRINT_AND_ASSEMBLE.md`, Phase 2.

| File | Qty | What it is |
|---|---|---|
| `upper_hub_closed_top.stl` | 1 | top cap (spins); holds the top of every blade |
| `lower_hub_closed_bottom.stl` | 1 | bottom cap (spins); holds the bottom of every blade |
| `bearing_support_stationary.stl` | 1 | fixed tower that holds the two ball bearings (needs supports under the ring) |
| `thrust_washer_top.stl`, `thrust_washer_bottom.stl` | 1 each (print spares) | tiny spacers for the bearings |
| `inlet_vent_louver.stl` | 2 | screened air inlets for the doghouse walls |
| `shaft_dimple_drill_guide.stl` | 1 | tool for drilling the two small dimples in the shaft |
| `roof_adapter_pick_ONE_for_your_roof_pitch/` | **1** | roof flange. Pick the file for your roof slope (`0in12` = flat, `4in12` = 4 in rise per 12 in). |
| `optional/rain_baffle_if_needed.stl` | 0–1 | drip tray, only if the water test shows leaks |
| `optional/lower_hub_SOLID_DISC_ALTERNATE_not_recommended.stl` | – | solid bottom cap; blocks most of the airflow, see `whirlybird/DESIGN_REPORT.md` |
