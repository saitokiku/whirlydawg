# Step 5 (optional) – 3D models for CAD software

Open these in Fusion 360, Onshape or FreeCAD to inspect or modify the design.
**`whirlybird_complete_assembly.step`** contains everything in its installed position.
The other files are single parts. All share the same origin: roof surface at the centre of the
shaft, Z pointing up.

To change sizes it is easier to edit `whirlybird/MASTER_PARAMETERS.json` and rebuild; that
regenerates every file in folders 1–5 and re-runs all the checks.
